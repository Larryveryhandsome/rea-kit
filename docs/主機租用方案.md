- **資料是你的**：客戶需求、物件、海巡設定、推播紀錄等所有資料，所有權歸租用者（仲介本人或店家）。

- 每位租用者的資料放在獨立資料夾與獨立服務程序；金鑰以加密方式保存。
- 你隨時可以在 LINE 打「匯出我的資料」自行下載，或打「刪除我的資料」刪除。

## 退租與資料匯出

1. 退租前任何時候：LINE 打「匯出我的資料」即可自行下載客戶與物件資料。
2. 提出退租後 **7 天內**，我們提供完整匯出包（ZIP：客戶需求 CSV、物件 CSV、海巡與個人設定 JSON；**不含金鑰**），可直接匯入你自己架設的開源版繼續使用。
3. 匯出後保留 **30 天**（讓你確認資料無誤），期滿刪除主機上的資料與備份，並以書面（LINE 或 Email）通知刪除完成。
4. 退租後請到 LINE Developers 把 Channel access token **重新發行**，舊 token 立即失效；Webhook 網址改成你的新主機或關閉。
5. 月繳：當月不退費，下個月起停止收費；年繳：依剩餘完整月份比例退費（原則上扣除已贈送月份），以報價單約定為準。
