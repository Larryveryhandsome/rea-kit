# 客人告知範本（仲介 → 他的客人）

> 個資法第 8 條：直接向當事人蒐集個資時，要告知蒐集者、目的、類別、利用期間／地區／對象／方式、當事人權利、不提供的影響。
> 客人的資料是**仲介自己蒐集**的；本服務只是替仲介保管（受託處理，見 `委託處理條款.md`）。所以告知由仲介做。
> **不是法律意見**；正式對外前請律師看。

## LINE 版（短，第一次記客人需求時傳一次）

仲介在 LINE 打「客人告知範本」，就會拿到這一段，裡面已經帶好他自己的署名，可以直接轉傳：

> 您好，我是{仲介署名}。
> 為了幫您找房，我會記下您的需求（想找的地區、預算、房型等，不需要身分證字號），只用來替您配對物件、和您聯絡；保存到您不再需要服務為止。
> 這些資料由我使用的房仲工具在台灣的主機保管，只有我看得到，不會提供給其他人。
> 您隨時可以請我查詢、更正或刪除；不想再收到物件資訊，跟我說一聲就好。
> 如果不方便提供需求，我就沒辦法替您配對物件，但不影響您自己看房。

這段寫在 `adapters/line/my_data.py` 的 `notice_text()`，改字要兩邊一起改。

## 完整版（書面、委託書或官網用）

| 告知事項 | 內容 |
|---|---|
| 蒐集者 | {仲介姓名}（{所屬公司／品牌}），聯絡方式：{電話或 LINE} |
| 蒐集目的 | 不動產仲介服務：了解購屋／租屋需求、配對物件、聯絡與帶看安排（法定特定目的：〇八一 個人資料之合法交易業務、〇九〇 消費者、客戶管理與服務） |
| 個資類別 | 稱呼（可用暱稱）、想找的地區、預算、房型、房數、坪數、屋齡、車位與電梯需求；您主動提供的聯絡方式 |
| 利用期間 | 從您提供起，到您表示不再需要服務、或最後一次聯絡後 {N} 個月，屆期刪除 |
| 利用地區 | 中華民國境內 |
| 利用對象 | 仲介本人。不提供給其他仲介或第三人；保管工具的提供者（受託處理者）只依仲介指示保管，不另作他用 |
| 利用方式 | 用電子方式保存與比對；用 LINE 或電話與您聯絡 |
| 您的權利 | 查詢、閱覽、複製、補充、更正、停止蒐集處理利用、刪除（個資法第 3 條）；跟仲介說一聲即可 |
| 不提供的影響 | 無法替您配對物件；不影響您自行看房或委託其他仲介 |

## 仲介要注意

- 只記找房需要的東西；**不要記身分證字號、病歷、收入證明**這類資料（系統也擋電話號碼當暱稱）。
- 客人說不要了：在 LINE 打「暫停 客戶編號」停止配對，或請管理員刪除那一位；整個帳號要刪，打「刪除我的資料」。
- 謄本資料（地號查詢結果）只能用在自己的業務；寄開發信一定要附「不想再收到請回覆」的拒絕方式。
