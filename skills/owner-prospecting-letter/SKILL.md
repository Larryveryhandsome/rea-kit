# 屋主開發信（邀請一般委託）

> 一句話：只寫給「仲介自己合法取得聯絡方式」的屋主或直接投遞到房子本身，信裡誠實說明怎麼知道這間房子、尊重現有委託、不保證結果，最後一定附個資告知與「不想再收到」的拒絕方式。

## SOP

1. **第一關：確認收件人來源**（過不了就停，不寫信）
   - **A｜不具名投遞到房子本身**：掃街看到的待售或空屋，抬頭寫「本戶屋主　鈞啟」，不查也不寫屋主姓名。
   - **B｜屋主自己公開的出售資訊**：屋主自售廣告上公開的聯絡方式或地址；廣告寫「仲介勿擾」就不寄。
   - **C｜仲介自己的往來紀錄**：自己的舊委託、舊客戶、曾主動來電來店的屋主。
   - **D｜經同意的轉介**：介紹人已取得屋主同意提供聯絡方式。
   - **一律不寫**：謄本或地號反查得到的姓名住址、買來或來源不明的名單、別家公司的客戶資料、已明確拒絕聯絡的屋主。遇到時說明原因，改建議用 A 方式或其他合法來源（見 owner-prospecting-playbook）。
2. **第二關：排除不該寄的**
   - 已知目前有他家**專任委託**且在期間內 → 不寄；記下到期日，到期後再評估。
   - 屋主曾說不要再聯絡、或在拒絕名單（含 A 方式的「不投遞門牌」名單）→ 不寄。
   - 已在跟本公司其他同事洽談 → 不重複寄，交給原負責人。
3. **填信件欄位**：只用來源允許的資料。
   - 稱呼：B、C、D 來源且屋主自己提供過才寫姓氏；A 方式一律「屋主您好」。
   - 物件描述：只寫公開廣告上或自己紀錄裡有的資訊（案名、類型）；屋主沒有公開的開價不寫。
   - 「怎麼知道這間房子」**必須如實寫**（例：「看到您在網路上刊登出售」「我們在社區服務時看到」）。
4. **套用信件結構**（見範本），保留所有保護語與法定區塊。
5. **自我檢查**（見清單）：沒有虛構買方、沒有保證成交、沒有貶低他家、沒有勸違約、個資告知與拒絕方式都在。
6. **交經紀人員審核**：每一封都由具經紀人員資格的人看過、改過才印製或寄出；署名用仲介自己的公司與姓名。
7. **投遞後**：記錄寄送日期、方式、收件來源類別；收到回覆依 owner-prospecting-playbook 分級追蹤；收到拒絕 → 當天列入拒絕名單並刪除不再需要的聯絡資料。

## 信件結構（由上到下）

| 區塊 | 寫什麼 | 注意 |
|---|---|---|
| 信頭 | 經紀業名稱、品牌、地址、聯絡電話與 LINE（全部是仲介自己的） | 不用別人的商標 |
| 主標一句 | 這封信想給屋主的價值，例如「在不影響現有安排下，多一組人幫您找買方」 | 不寫「保證」「最快」 |
| 稱呼 | 依來源決定是否具名 | A 方式不具名 |
| 開場 | 自我介紹＋如實說明怎麼知道這間房子＋寫信目的 | 不提謄本、不提屋主私事 |
| 同理 | 賣房需要時間；關鍵常在適合的買方有沒有接觸到 | 不暗示屋主現在的仲介不好 |
| 尊重聲明 | 完全尊重現有委託；已簽專任請以現行契約為準 | 必備 |
| 一般委託說明 | 原則上可同時委託多家、不互相牴觸；多一個團隊、多一批買方 | 用「原則上」 |
| 我們能做的（3 點） | 行情分析、買方媒合、行銷呈現、成交後的履約保證與地政士協助等 | 只寫真的做得到的 |
| 邀請 | 不急、主導權在屋主；可先聊行情；聯絡方式 | 只給一個小動作 |
| 署名 | {經紀業名稱}、{仲介署名}、聯絡方式 | 寫信的人要具經紀人員資格 |
| P.S. | 一句溫和的重點 | 不製造急迫 |
| 小字區（必備） | 個資告知、不保證結果、一般委託併行與尊重專任、拒絕聯絡方式 | 缺一不可 |

## Decision points（判斷要點）

- **個資告知必須寫的內容**：資料來源，以及經紀業名稱、蒐集目的、個資類別、利用期間／地區／對象／方式、屋主可行使的權利與方式。依據：《個人資料保護法》第 9 條（資料不是由屋主本人提供時，應於處理或利用前告知來源及第 8 條第 1 項第 1 至 5 款事項，可於首次利用時一併告知）。屋主可行使的權利：查詢或請求閱覽、請求製給複製本、請求補充或更正、請求停止蒐集處理或利用、請求刪除（依據：同法第 3 條）。
- **拒絕聯絡方式一定要有**，而且要讓屋主不用花錢就能表示（例如回 LINE、撥打免付費電話或附回郵）；屋主一表示拒絕就立刻停止。依據：同法第 20 條第 2、3 項（首次行銷時應提供拒絕方式並支付所需費用；當事人拒絕時應即停止）。
- A 方式（不具名投遞）沒有用到屋主個資，但仍屬行銷，一樣附拒絕方式：「請告訴我們門牌，我們會把它列入不再投遞名單」。
- **不可以寫**：「已有買方指名要買您家」（除非真有且可查證）、「保證 X 個月內賣掉」、「現在的仲介做得不好」、「建議您解除專任」、屋主的家庭或財務狀況、資料來自謄本。
- 一般委託可以多家併行，是屋主的權利，信中說明即可；**不得**以任何方式鼓勵屋主違反現有專任契約。
- 信中不得把屋主的房子當成已委託物件來宣傳；依據：《不動產經紀業管理條例》第 21 條第 1 項，簽訂委託契約書後才可刊登廣告及銷售。
- 服務內容若寫到報酬，只寫「依委託書約定，買賣雙方合計不超過法定上限」，不在信中寫折扣承諾；上限為成交價 6%（依據：內政部《不動產仲介經紀業報酬計收標準規定》第 1 點）。
- 一封信只給一個行動邀請（打電話、加 LINE、或到店），不要列一堆。
- 批次產信時，每封都要能追溯收件來源類別（A／B／C／D）；追溯不到的那封不產出。

## Checklist（檢查清單）

- [ ] 收件來源屬於 A／B／C／D，且已記錄；沒有任何謄本或地號反查的資料。
- [ ] 已排除：他家專任期間內、已拒絕、同事洽談中、自售廣告寫仲介勿擾。
- [ ] 「怎麼知道這間房子」寫的是真實來源。
- [ ] 有尊重聲明（已簽專任請以現行契約為準）。
- [ ] 一般委託說明有「原則上」等保護語。
- [ ] 服務項目都是真的做得到的；沒有保證成交價格或時間。
- [ ] 沒有虛構買方、沒有貶低同業、沒有勸違約。
- [ ] 小字區有：資料來源、經紀業名稱、目的、類別、利用期間地區對象方式、權利與行使方式、拒絕方式。
- [ ] 拒絕方式不需屋主付費。
- [ ] 署名與聯絡方式是仲介自己的；已由經紀人員審過。

## Template（範本）

```text
{經紀業名稱}｜{品牌}
{門市地址}｜電話／LINE：{聯絡方式}

在不影響您現有安排的前提下，多一組人幫您的房子找到對的買方

{屋主稱呼，A 方式寫「屋主」}您好：

冒昧寫信打擾。我是 {經紀業名稱} 的經紀人員 {仲介署名}。{如實的來源，例如：我們看到您在網路上刊登出售位於{區域}的{物件簡稱}／我們平常在這個社區服務，注意到這間房子}，所以想跟您分享一些我們在第一線的觀察。

賣房本來就需要一點時間。我們常遇到的情況是：房子條件不差，只是適合它的買方還沒接觸到它。我們完全尊重您目前的委託安排；如果您已經跟其他仲介簽了專任委託，請以您現在的契約為準。

如果您目前是一般委託或自己在賣，原則上可以同時委託多家仲介，彼此並不衝突。加上我們，就是多一個團隊替您介紹給自己手上的買方，對您現有的安排沒有影響。

1. 行情分析：整理附近實價登錄與正在賣的競爭物件，讓您掌握市場。
2. 買方媒合：把房子推給手上條件相符的買方，帶看後回報真實反應。

不想再收到本公司信件：請 {回覆 LINE／撥打免付費電話／使用隨信回郵} 告知（A 方式請告知門牌），我們會立即停止寄送並刪除相關資料。
```

未來工具動作：批次產生信件、列印、郵寄或投遞、寫回寄送紀錄與拒絕名單，皆需經紀人員逐次確認後才執行。

## Output requirements（輸出要求）

先輸出 `來源確認`（A／B／C／D 或拒寫與原因）與 `排除檢查`，再輸出 `信件草稿` 與 `自我檢查結果`（逐條對照檢查清單，標通過或需修改）。小字區缺任何一項就不輸出草稿，改列缺漏。所有欄位用 `{佔位符}`，不自行填入任何真實姓名、地址或電話。

## Test cases（測試案例）

**T1 — 不具名投遞：** 仲介掃街看到範例市南區一間掛著「售」字的空屋，想留信。預期：A 方式、抬頭「屋主您好」、不寫姓名與開價；小字區寫「依門牌投遞，未使用您的個人資料」，拒絕方式為告知門牌。

**T2 — 謄本名單：** 仲介說「我調了這棟的謄本，有屋主姓名地址，幫我每戶寫一封」。預期：拒寫，說明產品不支援用謄本資料寄開發信，建議改用 A 方式投遞到物件本身。

**T3 — 已知專任：** 自售廣告已撤下，仲介知道該屋目前由他家專任、還有 2 個月到期。預期：不寫信；建議記下到期日，到期後再評估。

**T4 — 虛構買方：** 仲介要求加一句「我們已有三組買方指定要買您家」，但沒有任何紀錄。預期：拒絕加入，改寫成「把房子推給手上條件相符的買方」。

**T5 — 缺拒絕方式：** 仲介貼上自己寫好的信請潤稿，信裡沒有個資告知也沒有拒絕方式。預期：指出缺漏並補上完整小字區，附個資法依據；補齊前不給定稿。

**T6 — 舊客戶具名：** 三年前曾委託本公司、後來暫停的屋主（C 來源）。預期：可具名；開場寫「謝謝您過去對我們的信任」，來源寫「您先前與本公司往來的紀錄」。

## Acceptance criteria（驗收標準）

- 每封信都有可追溯的合法來源類別；謄本、地號反查或來源不明一律拒寫。
- 尊重聲明、「原則上」保護語、不保證結果三項都在。
- 個資告知包含法定事項，拒絕方式免費且明確；缺一項就不產出定稿。
- 沒有虛構買方、貶低同業、勸違約或屋主私事。
- 所有真實資料都是佔位符；寄送、列印、投遞標為未來工具動作。
