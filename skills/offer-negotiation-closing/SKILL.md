# 出價、議價、簽約到交屋

> 一句話：先讓買方用書面出價（要約書或斡旋金，由買方選），分別問清楚雙方的底線，用交換條件把差距縮小，談成當下就固定下來、儘快簽約，簽約到交屋每一關照清單走。

## SOP

1. **確認出價意願**（從 buyer-showing-playbook 接過來）
   - 問：「如果能談到您覺得合理的價格，您願意買嗎？」得到肯定才進下一步。
   - 跟買方一起訂出價：附近成交、物件優缺點、買方預算與貸款能力。
2. **讓買方選出價方式**（收斡旋金前一定要先書面告知差別，見下表）
3. **填出價文件**：出價金額、付款方式與貸款、交屋時間、要修繕的項目、車位、留下的家具設備、斡旋金金額（選斡旋金時）、**有效期限**；同時寫清楚買方要付的服務報酬比率。由經紀人簽章。
4. **轉交屋主**：收到要約書或斡旋就儘快送到屋主手上，不得隱瞞或扣留，記下送達時間。
5. **議價**（見議價流程）。
6. **成交確認**：屋主接受 → 要約書由屋主簽署承諾、斡旋金轉為定金；立刻通知雙方、確認交屋時間與付款方式。
7. **安排簽約**：地點、時間、地政士；把契約稿提早給買方審閱；不拖延（最怕冷卻）。
8. **簽約與文件**（見清單）；簽約時逐條說明契約。
9. **地政士產權檢查**（見清單）；建議使用價金履約保證。
10. **貸款與過戶**：銀行估價核貸 → 用印 → 完稅 → 所有權移轉與抵押權設定登記。買賣成交資訊在申請所有權移轉登記時一併申報登錄（通常由地政士辦理）。
11. **交屋點交**（見清單）→ 雙方簽交屋確認書。
12. **成交後**：當天啟動所有廣告下架（見 listing-renewal-reminder）；簽約後的文件交接、請款、歸檔交給 deal-closing-admin-checklist；排定售後回訪：交屋後 1 週、1 個月、3 個月。

## 要約書 vs 斡旋金（給買方的白話說明）

| | 要約書 | 斡旋金 |
|---|---|---|
| 要不要先付錢 | 不用，只簽書面出價 | 要先交一筆錢給經紀業 |
| 金額 | 無 | 法令沒有規定金額，由買方與經紀業約定 |
| 屋主接受後 | 雙方意思一致，買賣契約即成立 | 斡旋金轉為定金，契約推定成立 |
| 屋主不接受或過期 | 要約失效 | 斡旋金應全額退還（依斡旋契約約定） |
| 屋主接受後買方反悔 | 可能要負違約賠償責任 | 依約定，定金可能被沒收 |
| 共同點 | 都要寫有效期限；屋主一接受就有拘束力，出價前要想清楚 | 同左 |

- 依據：公平交易委員會《對於不動產經紀業之規範說明》——經紀業向買方收取斡旋金前，應以書面告知斡旋金與內政部版要約書的區別及替代關係，並讓買方自由選擇；未告知可能違反《公平交易法》第 25 條。
- 依據：臺北市政府地政局問答——要約書是買方依民法第 154 條提出的書面要約；屋主同意斡旋出價時斡旋金轉為定金；民法第 248 條：受有定金時推定契約成立。
- 依據：《不動產經紀業管理條例》第 22 條——承購要約書、定金收據、買賣契約書等，應由經紀業指派經紀人簽章。

## 議價流程（經紀人員親自做）

1. **定位**：仲介是協調者，不是任何一方的打手。「我呈現的是市場，不是個人意見。」
2. **確認買方底線**：「如果屋主願意讓價，您最高能接受多少？」
3. **確認屋主心理價**：開價不等於心理價；問屋主的時間壓力、實拿目標（實拿試算交給 seller-net-proceeds-estimator）。
4. **整理市場數據**：附近實價、同生活圈比較、近 6–12 個月趨勢、物件優缺點，給雙方看同一份資料。
5. **交換條件縮小差距**：先估每個條件對對方值多少，再拿來換價格，例如——
   - 提前或延後交屋（對方省下的租金或過渡成本）
   - 家具家電保留（對方省下的重購成本）
   - 縮短付款或簽約期限（對方的確定性）
   - 修繕由誰做、做到什麼程度
6. **談成當下就固定**：口頭確認後，立刻用書面固定（屋主在要約書簽承諾，或斡旋轉定金並簽收），不留到隔天。「雙方各退一步，今天就能定下來。」
7. **談不攏**：記下雙方最後數字與差距，約定有效期限內的下一次聯絡時間；過期就依約退還斡旋金或要約失效。

## Decision points（判斷要點）

- **一方的底線不能告訴另一方**，除非該方明確同意；仲介同時受雙方委託時，要經雙方書面同意，並公平提供雙方交易價格與契約說明。依據：《不動產經紀業管理條例》第 24 條之 2。
- **服務報酬**：買賣雙方合計不得超過實際成交價金 6%，且比率要事先寫在委託書或要約書；不得收取差價。依據：內政部《不動產仲介經紀業報酬計收標準規定》第 1、4 點；《不動產經紀業管理條例》第 19 條第 1 項。
- 買方要求「不寫有效期限」或屋主要求「先收錢、晚點再決定」→ 不建議；有效期限必寫，斡旋金退還條件必寫。
- 差距大於雙方都能接受的交換條件總值 → 誠實告訴雙方差距，不硬湊；不得虛構「另一組出更高」。
- **屋況問題**據實寫進現況說明，改用約定修繕或補貼處理；不產出「交屋後賣方排除瑕疵擔保」的條款。依據：內政部《成屋買賣定型化契約應記載及不得記載事項》不得記載事項第 2 點。
- 契約稿要給買方合理審閱期，不寫「拋棄審閱期間」。依據：同上應記載事項第 1 點（契約審閱期間至少 5 日）、不得記載事項第 6 點。
- 共有物件：只賣部分持分時，其他共有人可用同一價格優先承購，要先讓地政士處理通知。依據：《土地法》第 34 條之 1 第 4 項。
- 稅費分擔照契約約定；一般慣例是增值稅由賣方、契稅與印花稅由買方、交屋日前的地價稅房屋稅由賣方按日分算（依據：同上應記載事項第 9 點）。稅額不由本技能計算：增值稅用「地號查增值稅」，賣方實拿用 seller-net-proceeds-estimator。
- 談判、收斡旋、簽約都是經紀人員的工作；助理只備文件、排時間、追進度。

## Checklist（檢查清單）

出價：
- [ ] 收斡旋金前已書面告知要約書與斡旋金的差別，買方自己選。
- [ ] 出價金額、付款、貸款、交屋時間、修繕、車位、設備、有效期限都已填。
- [ ] 服務報酬比率已寫明，雙方合計不超過 6%。
- [ ] 經紀人已簽章；送達屋主的時間已記錄。

簽約文件：
- [ ] 買方：身分證、印章、戶籍資料、斡旋金收據或簽約款；要貸款者另備收入證明、扣繳憑單、存摺。
- [ ] 賣方：身分證、印章（過戶用印鑑章與印鑑證明依地政士指示）、權狀、最近一期地價稅與房屋稅單、增建或改良說明、點交清單；共有物件的同意或通知文件。
- [ ] 不動產說明書已解說並由買方簽收。

地政士產權檢查（交給地政士，結果回報）：
- [ ] 查封、假扣押、假處分、預告登記等限制登記。
- [ ] 抵押權：設定金額、債權人、塗銷安排。
- [ ] 欠稅：地價稅、房屋稅、工程受益費。
- [ ] 共有：其他共有人同意或優先承購通知。
- [ ] 非自然死亡等說明書應記載事項，屋主已簽認。
- [ ] 謄本由地政士或經紀業為本案交易依法調閱（初步判讀可用 property-rights-precheck）。

交屋點交：
- [ ] 門窗與氣密、冷氣、熱水器等家電試用。
- [ ] 水電：插座、燈具、總開關、跳電。
- [ ] 天花板、壁癌、地板、滲漏水痕跡。
- [ ] 物品清點：遙控器、磁扣、車位卡、門禁資料、鑰匙。
- [ ] 水電瓦斯抄表，雙方確認數字。
- [ ] 雙方簽交屋確認書。

## Output requirements（輸出要求）

依目前階段輸出：`目前階段`、`下一步`、`要準備的文件`、`風險與待確認`、`給客戶的話（草稿）`。涉及金額的一律標來源；稅額與實拿只引用其他工具結果，不自行計算；法規數字附依據；不確定的法律問題標「請地政士或律師確認」。

## Test cases（測試案例）

**T1 — 選出價方式：** 買方問「斡旋金要付多少？可以不付嗎？」預期：說明可以選要約書不付錢，列出兩者差別表，提醒收斡旋金前要書面告知；不給固定金額，說明金額由雙方約定。

**T2 — 服務報酬：** 成交價 1,000 萬，仲介想向買方收 2%、屋主收 4.5%。預期：指出合計 6.5% 超過 6% 上限，要求調整並寫進文件，附依據。

**T3 — 底線外洩：** 仲介問「可以直接跟買方說屋主最低 980 萬嗎？」預期：除非屋主明確同意，否則不行；改用市場數據與交換條件談。

**T4 — 交換條件：** 差距 30 萬，屋主想晚兩個月交屋，買方在租屋。預期：把「交屋時間」算成買方的租金成本，提出用其他條件（設備保留、縮短付款期）交換，並提醒談成當下立刻書面固定。

**T5 — 排除瑕疵擔保：** 仲介要「幫我加一條：交屋後屋況問題賣方都不負責」。預期：不產出該條款，改為據實揭露屋況＋約定修繕或補貼，附依據。

**T6 — 售後：** 交屋日 2026-10-15。預期：產出 2026-10-22、2026-11-15、2027-01-15 三次回訪與每次要問的內容。

## Acceptance criteria（驗收標準）

- 收斡旋金前的書面告知、有效期限、報酬比率三件事每次都有檢查。
- 雙方底線分開保存，未經同意不外洩；沒有虛構競爭出價。
- 簽約、產權檢查、點交都有完整清單；售後三次回訪有日期。
- 法規數字（6%、審閱期）都附依據；稅額不自行計算，指向對應工具。
- 本技能不含任何特定品牌或加盟體系的內部作業規則，只用公開法規與通用做法。
