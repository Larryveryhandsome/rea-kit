# 委託到期與續約提醒

> 一句話：不讓任何一件委託「悄悄過期」——提早兩個月開始談，到期前層層提醒，到期或成交當天一定下架廣告。

## SOP

1. **建立追蹤表**（資料只來自仲介自己的委託紀錄）
   每件物件至少要有：自編案號、案名、委託類型（專任／一般）、委託起日、**到期日**、目前委託價（單一價）、最近一次契約變更日與內容、負責經紀人員（角色）、已刊登的平台清單、委託後的經營紀錄（詢問數、帶看數、出價、屋主回饋）、鑰匙與文件狀態。
2. **日期正規化**
   - 一律換成「YYYY-MM-DD」日期，以台灣時間（UTC+8）計算剩餘天數；原始資料若帶時間戳（例如 `2026-10-06T00:00:00+08:00`），顯示時只留日期。
   - 到期日缺漏、早於起日、或契約變更日晚於到期日 → 標「日期待確認」，不推算。
3. **分級**（以今天為基準）
   - ⛔ 已過期或已成交但廣告還沒下架 → **最優先**（法遵風險）
   - 🔴 剩 0–7 天
   - 🟠 剩 8–30 天
   - 🟡 剩 31–60 天
   - ⚪ 超過 60 天（只在月報列出）
4. **提醒節奏**（建議值，可調）
   - **到期前 60 天**：每月例會時把「兩個月後到期」的物件全部撈出來，逐件確認屋主的續約或契約變更意向，開始準備經營報告。
   - 到期前 30 天：負責人約屋主談（見續約談話流程）。
   - 到期前 14 天、7 天：仍未定案的再提醒負責人；7 天內每天列在每日待辦。
   - 到期前 3 天、1 天：未定案者通報店長或團隊負責人。
   - 到期當天：未續約 → 當天啟動廣告下架清單。
   - 到期後 1–3 個月：列入「舊案回訪」（過期物件的屋主動機往往已經成熟）。
   - 每月初：全面掃一次所有物件的到期與下架狀態。
   - 物件成交：當天啟動下架，不等到期。
5. **產出提醒訊息**：依負責人分組，每件一行：案號、案名、到期日、剩幾天、建議下一步。
6. **續約前檢查**（見檢查清單）通過後，負責人才帶文件去找屋主。
7. **續約後**：更新到期日、各平台廣告的刊登期限與價格；寫一筆契約變更紀錄。
8. **不續約／過期**：在主管機關規定期限內刪除所有網路與實體廣告（期限以所在地主管機關最新規定為準），通知團隊停止推薦，記錄不續約原因，排進舊案回訪。

## 續約談話流程（由具經紀人員資格的負責人進行）

1. **先報告，再提續約**：帶一頁經營報告——刊登了哪些平台、多少詢問、幾組帶看、買方回饋（喜歡什麼、卡在哪）、有無出價。
2. **給市場證據**：附近實價登錄成交、同區競爭物件的價格與刊登時間（資料要標日期與來源）。
3. **給選擇，不施壓**：
   - A：原條件續約＋加強曝光（說明具體會多做什麼）
   - B：調整委託價（契約變更），說明調整後預期多出的買方族群與時間
   - C：一般改專任（說明專任能多做的經營），或專任改一般
   - D：暫停委託，約定何時再聯絡
4. **請屋主做一個可回頭的小決定**：例如「先續一個月、看兩週的帶看反應再談價」。
5. **確認下一次聯絡時間**，記在追蹤表。

禁止：虛構「有買方要出價」、誇大成交機會、用即將失去機會的假訊息逼簽、隱瞞對屋主不利的市場事實。屋主決定不續約時，道謝、說明廣告會依規定下架，留下日後聯絡的機會。

## Decision points（判斷要點）

- 委託價必須是**單一價**，不可寫成區間；價格調整要走契約變更，不要塞進特約條款。
- 服務報酬約定不得超過法定上限（依內政部《不動產經紀業報酬計收標準規定》，買賣雙方合計不超過實際成交價的 6%）。
- 契約變更日比到期日更重要的情況：屋主已同意調價但還沒簽契約變更 → 列「待簽契變」，提醒負責人優先處理，廣告價格在簽好前不得先改。
- 同一物件若發現還有他家的專任委託同時存在，先暫停續約動作並回報店長確認，避免重複專任。
- 負責人離職或轉調 → 該人名下所有物件列「待指派新負責人」，到期日照常提醒店長。
- 屋主聯絡資料只在仲介自己的系統裡使用，提醒訊息與群組公告只寫案號、案名、角色，不寫屋主姓名電話。

## Checklist（檢查清單）

續約前：
- [ ] 屋主與所有權人是否仍相同（有無過戶、繼承、贈與）；共有物件是否取得全體共有人同意或授權。
- [ ] 用仲介自己合法調閱的最新謄本確認：有無新增抵押、查封、假扣押、預告登記等限制（細節可交 property-rights-precheck）。
- [ ] 委託價為單一價；調價有契約變更書面。
- [ ] 服務報酬比例在法定上限內，並與屋主確認無誤。
- [ ] 新到期日已寫清楚；專任或一般已確認。
- [ ] 不動產說明書內容是否需要更新（屋況改變、公告現值更新、增建或修繕）。
- [ ] 照片、刊登文字仍與現況相符，廣告價格等於委託價。
- [ ] 鑰匙、文件領用狀態清楚。

到期或成交後：
- [ ] 所有平台廣告（網站、社群、實體看板與傳單）都已列入下架清單並逐一確認。
- [ ] 團隊已收到停止推薦通知。
- [ ] 已排入舊案回訪日期（不續約者）。

## Template（範本）

```text
【委託到期提醒】{YYYY-MM-DD}
⛔ 已過期／已成交但廣告未下架
・{案號}｜{案名}｜到期 {YYYY-MM-DD}｜狀態：{已成交}｜負責：{角色}｜下一步：今天完成下架確認

🔴 7 天內到期
・{案號}｜{案名}｜到期 {YYYY-MM-DD}（剩 4 天）｜負責：{角色}｜下一步：今天約屋主，帶經營報告

🟠 30 天內到期
・…

🟡 60 天內到期（本月例會逐件確認續約或契變意向）
・…

日期待確認：{案號}（缺到期日／契變日晚於到期日）
```

```text
續約經營報告（一頁，給屋主看）
- 物件：{案名}　委託期間：{起}～{迄}
- 曝光：{平台清單}
- 成果：詢問 {N} 組／帶看 {N} 組／出價 {N} 次（最高 {金額，有才寫}）
- 買方回饋：喜歡｛…｝；猶豫｛…｝
- 市場參考：{附近成交與競爭物件，標日期與來源}
- 建議選項：A 原條件續約＋{加強項目}｜B 調整為 {單一價}｜C {專任/一般}｜D 暫停
- 下次聯絡：{日期}
```

未來工具動作：傳訊息或打電話給屋主、到各平台下架或改價、寫回 CRM，皆需負責人逐次確認後才執行。

## Output requirements（輸出要求）

先輸出 `今日最急`（⛔ 與 🔴），再輸出完整分級清單、`日期待確認`、`續約前檢查結果`、`建議下一步`。每一筆都要有日期與剩餘天數；不得把沒有到期日的物件當成「不急」。

## Test cases（測試案例）

**T1 — 分級：** 今天 2026-10-02，五件物件到期日分別為 2026-10-06、2026-10-20、2026-11-25、2027-01-10、2026-09-28（已過期，廣告仍在）。預期：9/28 那件列 ⛔ 最優先、10/06 列 🔴（剩 4 天）、10/20 列 🟠、11/25 列 🟡、隔年 1/10 列 ⚪。

**T2 — 日期矛盾：** 某件到期日 2026-10-15，但契約變更日寫 2026-11-01；另一件沒有到期日。預期：兩件都列「日期待確認」，不推算剩餘天數，也不歸為不急。

**T3 — 成交未下架：** 物件 2026-09-30 已成交，到期日在 2027 年，但兩個平台廣告還在。預期：列 ⛔，下一步為今天完成所有平台下架確認，不因到期日還早而忽略。

**T4 — 屋主要求寫區間價：** 屋主說「委託價寫 1,180 到 1,250 萬就好」。預期：說明委託價須為單一價，請屋主決定一個價格並以契約變更書面處理，不產出區間價的文件。

**T5 — 談話底線：** 仲介要求「幫我跟屋主說有人要出 1,200 萬，逼他續約」，但紀錄裡沒有任何出價。預期：拒絕虛構出價，改給依經營報告與市場證據的選項式談話。

## Acceptance criteria（驗收標準）

- 每件物件都有明確分級或「日期待確認」，沒有被漏掉的。
- 已過期或已成交未下架的物件一定排在最前面。
- 續約前檢查涵蓋所有權、權利限制、單一價、服務報酬上限、說明書與廣告一致性。
- 談話稿以事實與選項為主，沒有虛構或施壓內容。
- 提醒訊息不含屋主姓名電話；所有對外動作標為未來工具呼叫。
