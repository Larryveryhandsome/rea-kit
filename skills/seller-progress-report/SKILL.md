# 屋主進度週報與賣方訊號

> 一句話：每週用證據回答屋主「有沒有在幫我賣」，並從對話裡挑出「今天該回頭找屋主」的理由——每個理由都附原句與誰說的。

## 參數

- 物件清單（租戶自己的在售物件）：`{自編案號}`、`{案名}`、行政區、類型、開價、委託簽約日、到期日、負責人（角色）
- 推播紀錄：每件物件推給了哪些買方（買方代碼）、哪一天推的（只算真的送達的，三態規則同 `listing-push-quality-gate`）
- 競爭物件：同行政區、同類型、目前在售的公開開價（來源與抓取日期要標）
- 對話紀錄：與屋主的群組或一對一訊息（時間、發言者是否為業務、內容）
- 門檻（預設值，租戶可調）：見判斷要點

## SOP

1. **只看在售的買賣物件**，已成交、已下架、委託過期的不列。
2. **每件算五個數字**
   - 上架天數＝今天－委託簽約日（續約者用續約日）。
   - 推給幾組買方（累計）、本週推給幾組、最近一次推播日。
   - 同區同類型在售幾件、開價中位數、「比你便宜的比例」＝開價低於本件的件數 ÷ 競爭件數。
   - 委託剩幾天＝到期日－今天。
3. **依建議規則給一句建議**（判斷要點 A，由上往下，命中第一條就停）。
4. **判斷賣方階段**（判斷要點 B），附判斷依據的原句。
5. **找訊號**（判斷要點 C），每個訊號算優先度、附原句、標明「屋主說的」或「業務說的」。
6. **排序**：先依訊號優先度，再依「本週推播組數少」「累計推播少」，最沒動靜的排最前。
7. **產出週報給負責人**（不是給屋主）：依負責人分段、合併成一則，每人先列最沒動靜的 3 件，其餘看完整清單。
8. **附「可以直接轉給屋主的話」草稿**：只放事實數字，由負責人確認、修改後自己轉發。
9. **負責人回報後更新**：屋主回覆、帶看、出價等新事件寫回紀錄，下週重算。

## Decision points（判斷要點）

### A. 每件物件的建議（由上往下，命中即停）

1. 委託剩 30 天內 → 「委託快到期，先準備經營報告」，交 `listing-renewal-reminder`。
2. 累計推給 0 組買方 → 「還沒推給任何買方：先確認需求配得上，或檢查賣點與照片」。
3. 本週推給 0 組 → 「本週沒有新買方看到（累計推過 N 組），主動回問舊客」。
4. 比你便宜的比例 ≥ 70% → 「同區同類型有 X% 比你便宜，價格是目前最大阻力，建議約屋主談價」，交 `owner-pricing-negotiation`。
5. 上架超過 90 天且累計推播少於 3 組 → 「曝光不足，加社群、加現場曝光、加開發買方」。
6. 其他 → 「進行中，維持曝光」。

競爭物件少於 3 件 → 不算比例，寫「同區樣本不足」，不給價格建議。

### B. 賣方階段（命中最後面的階段＝目前位置）

| 階段 | 只用「幾乎只會出現在這階段」的詞 |
|---|---|
| 爭取委託中 | 委託、專任、估價、調謄本 |
| 上架銷售中 | 已上架、廣告、開價、已簽委託 |
| 帶看中 | 帶看、約看、複看、來看現場 |
| 議價中 | 斡旋、出價、要約、回價、議價 |
| 成交簽約 | 簽約、用印、完稅、交屋、過戶、履保 |

判準寧窄勿寬：階段判錯比不判更糟。全部沒命中 → 「剛開始／未判定」。

### C. 該回頭找屋主的訊號（優先度 0–100，取最高者）

| 訊號 | 條件 | 優先度 |
|---|---|---|
| 出價剛談不攏 | 強烈詞（打退堂鼓、談不攏、破局、不買了、撤回斡旋）；或軟性詞（嫌貴、猶豫、卡在價格）**同時**提到一組具體買方（斡旋、出價、這組客人） | 60 天內 100；更早 60 |
| 屋主想收回、不賣 | 屋主本人說「不賣了、收回、解約、先不賣」，90 天內 | 95 |
| 說要聊卻沒下文 | 業務說過「找時間過去聊、再約」，之後滿 7 天沒有任何實質互動 | 90 |
| 屋主自己提價格或別家仲介 | 屋主本人說「可以談、底價、讓價」或提到其他仲介、自己賣，90 天內 | 85 |
| 從未帶看 | 建立對話滿 21 天，紀錄裡從沒出現帶看 | 75 |
| 委託到期或續約被提起 | 120 天內任一方提到到期、續約、展延 | 70 |
| 長期沒帶看 | 上次帶看距今 ≥ 21 天 | 65 |
| 屋主從沒開口 | 建立對話滿 21 天，屋主一句話都沒說過 | 55 |
| 久未實質互動 | 排除群發罐頭後，≥ 14 天沒有互動 | 50 |

- **「出價剛談不攏」＝屋主最可能願意重新談價的時刻**，一定排最前，並建議負責人一週內約屋主。
- **屋主的態度只採信屋主自己說的話**：業務說「我在拉他的價格」不等於屋主願意降。想降價、想收回、提到別家仲介，三種都只看屋主本人的發言。
- **成交事件可以採信業務的話**（出價、談不攏、帶看、簽委託），因為屋主往往還不知道；但輸出時一定標「業務說的」。
- **群發罐頭不算跟進**：同一段文字（至少 8 個字）出現在 3 個以上不同屋主的對話裡＝群發，不算「這件有人在跟」，也不拿來判階段或訊號。
- **誰是業務**：同一個帳號出現在很多不同屋主的對話（預設 ≥ 5 個）＝業務或團隊；只出現在自己那一個的＝屋主。用資料分佈判斷，不靠人維護名單。
- **防誤判**：「價格不變」「價格再談談」這類字面上有「價格」但意思相反的句子，不得命中「談不攏」；必須有強烈詞，或軟性詞＋具體買方。
- **別家仲介的詞**：用完整名稱（租戶自訂清單），不要用兩個字的簡稱——路名、地名常常剛好一樣。也不得把租戶自己所屬品牌當成競爭者。
- **不猜結果**：只標訊號與根據，不寫「屋主一定會降價」；決定權在負責人。

## Checklist（檢查清單）

- [ ] 每件在售物件都有五個數字；缺資料的寫「無資料」，不填 0。
- [ ] 推播組數只算真的送達的。
- [ ] 競爭物件標了來源與抓取日期；樣本少於 3 件不給比例。
- [ ] 每個訊號都附原句（最多 60 字）、日期、誰說的。
- [ ] 屋主態度類訊號全部來自屋主本人。
- [ ] 群發罐頭已排除。
- [ ] 週報給負責人，不直接送屋主；同一週合併成一則。
- [ ] 不含屋主姓名電話，只用案號、案名、角色。

```text
【{角色}】共 {N} 件
・{案名}｜上架 {N} 天｜推過 {N} 組（本週 {N}）｜同區 {N} 件在賣、{X}% 比你便宜｜委託剩 {N} 天
　→ {建議}
・…

🔔 今天該回頭找屋主
・{案名}【{階段}】優先度 {N}
　- {MM-DD}（{N} 天前）有人出過價但談不攏（業務說的）→ 屋主現在最可能願意重新談價
　  原句：「{原句}」
```

```text

```

未來工具動作：發送週報、轉給屋主、寫回 CRM，都要負責人逐次確認。

## Output requirements（輸出要求）

先輸出 `今天該回頭找屋主`（依優先度），再輸出 `每週進度表`（依負責人分段）、`可轉給屋主的話`、`資料缺口`。每個訊號都要有原句、日期、誰說的；每個建議都要能對回 A 表的哪一條。不輸出屋主姓名、電話、地址門牌。

## Test cases（測試案例）

**T1 — 出價談不攏：** 業務 20 天前在屋主對話寫「原本出價的那組客人因為價格打退堂鼓了，找時間跟您聊聊」，之後沒有任何互動。預期：命中「出價剛談不攏」優先度 100（標業務說的）與「說要聊卻沒下文」90，排最前，建議一週內約屋主。

**T2 — 防誤判：** 業務寫「如果價格不變，我們下週去跟您簽專任」。預期：不命中「談不攏」，階段判為爭取委託中。

**T3 — 屋主態度只信屋主：** 業務寫「我正在拉屋主的價格」，屋主本人沒提價格。預期：不產生「屋主自己提價格」訊號。

**T4 — 群發罐頭：** 「午安，持續為您銷售推薦中」同一天出現在 12 個屋主對話，某件除此之外 25 天沒互動。預期：罐頭不算互動，命中「久未實質互動 25 天」。

**T5 — 價格阻力：** 本件開價 1,280 萬，同區同類型 10 件中有 8 件比較便宜，本週推 2 組。預期：比例 80%，建議約屋主談價並交 `owner-pricing-negotiation`。

**T6 — 樣本不足：** 同區同類型只有 2 件。預期：寫「同區樣本不足」，不給價格建議，改用其他規則。

**T7 — 要求直接發給屋主：** 仲介說「直接幫我把週報發到每個屋主群」。預期：只產草稿給負責人，說明需逐次確認後由工具層送出。

## Acceptance criteria（驗收標準）

- 每件在售物件都有上架天數、推播組數、競爭排名（或樣本不足）、委託剩餘天數與一句建議。
- 「出價剛談不攏」一定排在最前，並附原句與說話者。
- 屋主態度類訊號沒有任何一筆來自業務的話。
- 群發罐頭不會讓沒人跟的物件看起來很熱鬧。
- 週報只給負責人、合併成一則；給屋主的話只含可查證的事實。
