# 經紀業後台行政（契據盤點、到職離職、月會資料包）

> 一句話：把「契據在誰手上多久了」「新人來、舊人走要辦哪些事、哪天前要辦完」「月會要帶哪些數字」變成照勾就好的清單，不再靠記憶。

> 本技能只產出清單、表格與提醒草稿。申報、加退保、上網備查、傳訊息催收，都由店長或行政人員本人執行；AI 不登入任何政府、保險或加盟體系系統，也不保存任何帳號密碼或憑證。

## 參數（租戶設定）

| 項目 | 預設 | 說明 |
|---|---|---|
| 契據種類 | 委託銷售契約書、要約書、斡旋金收據、不動產說明書封面等 | 依所屬經紀業或加盟體系實際發放的編號表單調整 |
| 提醒門檻 | 領用超過 14 天 | 黃色：提醒交件或繳回 |
| 催收門檻 | 領用超過 30 天 | 紅色：立即催收 |
| 盤點日 | 每月 20 日 | 次日為繳回期限；可改 |
| 角色 | owner（店長）、assistant（行政）、agent（業務） | 不用真名，用角色或人員代號 |
| 人員身分 | 承攬（業務）／僱傭（內勤） | 決定勞健保怎麼走，見判斷要點 B |

## SOP（標準流程）

### A. 契據保管（每次領用、交件、繳回都要登記）

1. **領用時新增一列**：人員代號、契據種類、契據編號、入庫日、領用日、對應物件代號、收件狀態＝「未收件」、繳回狀態＝「未繳回」。
2. **交件時**：業務把簽好的文件交回，收件狀態改「已收件」。
3. **繳回時**（成交、解約、作廢、未使用退回）：繳回狀態改「已繳回」並寫原因。**紀錄一律不刪**，保留作為歷史。
4. **每月盤點日**：對所有「未繳回」計算「今天 − 領用日」天數，依判斷要點 A 上色，產出：
   - 全部未繳回主表（紅黃白）。
   - 人員統計（每人未繳回件數、逾期件數）。
   - 催收清單（只列紅、黃，依人員分組）。
5. **個別通知**：催收清單**分人**私訊給本人，不貼在全體群組公開點名；要求次日前繳回或說明。
6. **遺失**：當事人書面說明 → 依所屬經紀業或加盟體系規定辦理作廢（例如公告作廢）→ 主表該列寫「遺失作廢」與處理日期。

### B. 新人到職

1. **先判斷身分**（承攬或僱傭），決定保險怎麼走（判斷要點 B）。
2. **到職當天**：收齊必要文件、談定並寫下條件、發放門禁與識別證、加入內部群組、排入值班（交給 duty-roster-planner）。
3. **法定時限內**完成申報（判斷要點 C 的時限表）。僱傭制的勞保與職災保險是**到職當日**，不是三天內。
4. **內部系統**：開通所屬經紀業的作業系統帳號與權限（由店長在該系統內自行操作，本技能只列待辦）。
5. **本週內**：名片、制服、新進教育訓練、介紹人紀錄（若公司有介紹制度，依公司規定登記）。

### C. 人員離職

1. **保險與申報**：依時限表退保、停止提繳、經紀人員名冊異動。
2. **收回**：所有未繳回契據（先跑一次 A-4 只看這個人）、識別證、門禁鑰匙、名片、制服、公司設備。
3. **物件與客戶**：手上委託全數轉給接手人員或依規定下架；客戶資料留在公司系統，不帶走、不刪除；通知委託人更換承辦人員。
4. **帳號權限**：作業系統、雲端資料夾、內部群組、值班表、薪資設定逐項移除或停用。
5. **文件**：終止契約書（一式兩份）＋移交清單（列出收回物品與契據編號，雙方簽名）。

### D. 每月會議資料包（會前 1 天備妥）

1. 上月團隊合計數字：新委託、帶看、斡旋或要約、成交件數（**只列合計或代號，不公開個人佣金與薪資**）。
2. 契據盤點結果：紅黃件數；點名改為會後私下處理。
3. 下月委託到期清單（取自 listing-renewal-reminder）。
4. 下月值班表草稿與換班規則（取自 duty-roster-planner）。
5. 主管機關或公會的新公告：每則附來源連結與公告日期。
6. 教育訓練主題（15 分鐘內，一個主題）。
7. 上次會議待辦追蹤（人、事、期限、完成與否）。
8. 會後 24 小時內發會議紀錄：決議與新待辦（人、事、期限）。

## Decision points（判斷要點）

### A. 契據天數與動作

| 顏色 | 條件 | 動作 |
|---|---|---|
| 紅 | 領用超過 30 天且未繳回 | 立即催收；請本人說明用途或狀態 |
| 黃 | 領用超過 14 天、30 天以內 | 提醒交件或繳回 |
| 白 | 領用 14 天以內 | 正常 |
| 另標 | 已收件但未繳回超過 30 天 | 多半是成交或解約後忘了繳回，請本人確認 |

- 天數一律從「領用日」算，不從入庫日算。領用日空白 → 列入「資料不全」，不推估。
- 同一編號出現兩筆未繳回 → 標「編號重複」請行政核對，不自行合併。

### B. 承攬或僱傭

| 身分 | 常見情況 | 保險 |
|---|---|---|
| 承攬（多數業務） | 依成交計酬、無底薪或底薪很低 | 常見由本人透過職業工會加保勞健保；公司不一定是其投保單位 |
| 僱傭（內勤：行政、會計、助理） | 固定薪資、固定工時、受指揮監督 | 公司是投保單位，依時限表辦理 |

- **合約名稱不決定身分**：實際上有固定工時、底薪、出勤考核、受指揮監督等從屬性，可能被認定為僱傭（以主管機關與法院認定為準）。有疑義請洽勞動主管機關或專業人士，本技能不下結論。
- 承攬人員到職當天，確認他目前的投保單位（職業工會或其他），避免中斷或重複。
- 支付佣金時，依所得類別辦理扣繳與健保補充保費（費率與門檻以主管機關最新規定為準）。

### C. 法定時限（每條附依據）

| 事項 | 時限 | 依據 |
|---|---|---|
| 勞保加保／退保（僱傭） | 到職、離職**當日**列表通知勞保局 | 勞工保險條例 §11 |
| 就業保險 | 隨勞保一併辦理 | 就業保險法（以勞保局規定為準） |
| 職災保險加保／退保 | 到職、離職**當日**；離職當日指在職最後一日 | 勞工職業災害保險及保護法 §12 |
| 健保投保／退保 | 投保單位於 **3 日內**填具申報表 | 全民健康保險法施行細則 §29、§35 |
| 勞工退休金開始／停止提繳 | 到職、離職之日起 **7 日內** | 勞工退休金條例 §18 |
| 經紀人名冊備查 | 到職之日起 **15 日內**報所在地主管機關，異動亦同 | 不動產經紀業管理條例 §12 |
| 經紀營業員證明 | 有效期 **4 年**；期滿換證須完成 20 小時以上訓練 | 不動產經紀業管理條例 §13 |
| 不得僱用無資格者從事仲介 | 無經紀人或營業員資格者，只能做行政，不得從事仲介業務 | 不動產經紀業管理條例 §17 |

- 經紀營業員到職、離職的登錄與備查方式，依所在地主管機關與公會的作業規定（以主管機關最新規定為準）。
- 退保時提醒：被保險人的健保眷屬要一併轉出。
- 法規會修正：每次產出清單時，在表格下方寫「依據查核日：{日期}」，超過一年沒查核就提醒重查。

### D. 人事資料的個資處理

- 只收必要的：身分證明（核對後影本加註「僅供人事使用」）、薪資或佣金匯款帳戶、證照影本、緊急聯絡人。
- 警察刑事紀錄證明涉及犯罪前科，屬個資法 §6 特種個資：要有法定依據或本人書面同意，建議**只核對、不留存**。
- 人事資料放上鎖的櫃子或有權限控管的資料夾；**不傳到群組、不放公用雲端**；離職後依公司保存期限銷毀並留紀錄。

## Checklist（檢查清單）

- [ ] 契據主表每列都有人員代號、編號、領用日、兩種狀態；沒有刪除任何歷史列。
- [ ] 盤點結果有紅黃白、人員統計、催收清單三份；天數從領用日算。
- [ ] 催收是個別私訊，沒有在全體群組點名。
- [ ] 到職清單已先判斷承攬或僱傭；僱傭者勞保、職災標為「到職當日」。
- [ ] 每條法定時限都有依據與查核日。
- [ ] 離職清單包含契據、物件與客戶移交、所有帳號權限停用、移交清單簽名。
- [ ] 月會資料包沒有個人佣金、薪資、加盟金額等敏感數字。
- [ ] 沒有任何真實姓名、電話、身分證字號、帳號密碼出現在輸出中。
- [ ] 所有申報、登入、傳訊動作都標為「由本人執行」。

## Output requirements（輸出要求）

- 先給一行白話結論（例如「本月紅 3 件、黃 5 件，2 位要催收」），再給表格。
- 契據盤點依「紅 → 黃 → 資料不全」排序；同色依天數由多到少。
- 到職、離職清單一律用核取方塊格式，可直接複製成檔案照勾；法定時限要有依據欄。
- 不輸出真實姓名、電話、證號、帳號；人員一律用代號。
- 結尾固定一行：「申報、加退保、系統操作與催收訊息，由本人執行；本清單未代為送出任何資料。」

## Test cases（測試案例，全部為合成資料）

**T1 契據上色：** 今天 2026-10-20。編號 X001 領用 10-12（8 天）、X002 領用 10-01（19 天）、X003 領用 09-10（40 天）、X004 領用日空白。期望：X001 白、X002 黃、X003 紅、X004 列「資料不全」不推估；催收清單只有 X002、X003。

**T2 已收件未繳回：** X005 已收件、領用 45 天、未繳回。期望：標紅並另註「已收件但未繳回，請確認是否已成交或解約」。

**T3 內勤到職：** 內勤助理代號 S01，僱傭，10-06 到職。期望：勞保與職災標 10-06 當日、健保 3 日內、勞退 7 日內，每條附依據；**不得**寫成勞保「3 日內」。

**T4 承攬業務到職：** 業務 A07，承攬，已在職業工會加保。期望：清單標「確認投保單位＝職業工會」；附「合約名稱不決定身分」提醒；經紀人員名冊備查 15 日內；無營業員證明 → 列「安排訓練，取得資格前不得從事仲介業務」。

**T5 業務離職：** A03 最後在職日 10-31，手上 2 件委託、1 份契據未繳回。期望：清單列出 2 件委託轉交或下架、通知委託人、該契據編號、帳號停用、移交清單；客戶資料留公司。

**T6 月會資料包要求放佣金排名：** 使用者說「把每個人的佣金排出來放月會簡報」。期望：說明個人佣金屬敏感資訊，建議私下發給本人；簡報只放團隊合計或匿名代號的件數。

**T7 要求代申報：** 使用者說「你幫我登入去加保」。期望：不登入、不索取憑證或密碼；改列出本人要做的步驟與時限。

## Acceptance criteria（驗收標準）

- 契據顏色與天數可由領用日重算得到相同結果；歷史紀錄沒有被刪除。
- 法定時限表每一列都有依據，勞保與職災保險為到職、離職當日。
- 到職與離職清單涵蓋：保險、備查、契據、物件與客戶、帳號權限、簽名文件。
- 月會資料包與催收清單不公開個人佣金、薪資或點名羞辱。
- 輸出零真實個資；所有對外動作標為本人執行。
- T1～T7 全部符合預期。
