# 物件事實卡 → 合規物件文案

> 本 skill 只產「草稿」。不發文、不排程、不登入任何平台。法條說明是白話整理，不是法律意見；條文以全國法規資料庫最新版本為準。

## 參數（從租戶設定讀，程式與範本裡不寫死）

- 位置：`{縣市}`、`{行政區}`、`{路街段}`、`{生活圈暱稱}`（選填，租戶自訂別名）
- 揭露：`{經紀業名稱}`、`{加盟店標示}`（直營留空）、`{經紀人員姓名}`、`{經紀人員證書字號}`、`{聯絡方式}`
- 平台：`fb_personal`／`fb_page`／`fb_group`／`threads`／`line_group`／`line_1on1`；印刷品：`print_newspaper`（報紙分類稿）／`print_dm`（DM 物件表）／`sale_sign`（售屋招牌、布條）（可多選）
- 印刷字數：`{報紙標題字數上限}`（預設 8）、`{報紙說明字數上限}`（預設 12）；照片張數、尺寸、交稿日依刊登單位或印刷廠的稿約填入
- 風格：`克制質感`（預設）／`親切在地`／`數據說明`
- 輸出：`text`（預設）／`json`

## SOP（標準流程）

1. **收事實卡**：每一欄要附來源（委託書、不動產說明書、建物／土地登記資料摘要、屋況說明書、屋主告知、仲介現場目測）。沒有來源的欄位只能列進「待確認」，不能寫進文案。
2. **三道門檻，任一道不過就不寫，只回報缺什麼**：
   - 有有效委託（委託人是仲介本人或所屬經紀業、到期日未過）。
   - 物件狀態是「銷售中」，且最後確認時間在 24 小時內。
   - 必附揭露齊全：`{經紀業名稱}`（加盟店含加盟標示）、`{經紀人員姓名}`。
3. **去敏**：地址只到路／街／段；地號只到段；不寫門牌、巷弄號、戶別；樓層寫「X 樓／共 Y 樓」即可；社區名稱要屋主同意才寫；屋主姓名、職業、出售原因（除非屋主同意且無個資）一律不寫。
4. **依平台結構寫**（見範本）：標題 → 關鍵數字 → 3–5 個賣點（每點都對得到事實卡）→ 生活機能（寫距離與量法）→ 必要揭露 → 一個行動呼籲 → 經紀業與經紀人員。印刷品照「印刷品格式」的欄位與字數寫，字數超過就重寫成短語。
5. **跑四張詞表與踩雷表**（見判斷要點）。命中「法遵禁用」或「平台紅線」必改；無法改寫的句子（事實本身沒有來源）直接刪除並列入「待確認」。
6. **一致性檢查**：價格、坪數、房數、樓層在每個平台版本完全相同，也要和圖卡（listing-visual-brief）同一組數字。
7. **交付**：各平台草稿＋事實對照表＋命中詞與改寫＋待確認清單。最後一行固定：「草稿，由仲介本人確認後在自己的帳號貼出。」

## Decision points（判斷要點）

### 法律底線（白話）

- **不動產經紀業管理條例第 21 條**：簽了委託契約才可以刊登廣告；廣告內容要與事實相符，並註明經紀業名稱。
- **加盟店**：依公平會對不動產經紀業的規範說明，廣告要讓人看得出是加盟店，不可讓人誤認為直營或總公司。
- **公平交易法第 21 條**：對價格、面積、用途、屋況、交通、學區、公共設施、建材等「會影響買不買」的事項，不可虛偽不實或引人錯誤；違反可被限期改正並處罰鍰（第 42 條）。
- **消費者保護法第 22 條**：廣告內容會變成對買方的義務。寫了「含車位」「可入籍」「附家電」，就要做得到。
- **經紀人員**：本 skill 預設每篇都附經紀人員姓名，證書字號建議附上（多數刊登平台要求，也讓買方查得到負責的合格人員）；缺字號時標「建議補」，不擋稿。

### 不動產廣告常見踩雷（逐條對）

| 項目 | 不可以 | 改成 |
|---|---|---|
| 面積 | 把公設、車位、露台、增建算進「坪數」卻不說明 | 分列主建物／附屬建物／公設／車位，總坪數註明含哪些 |
| 增建 | 頂樓加蓋、陽台外推、夾層算進權狀坪或房數 | 另列「增建部分非登記面積，有被拆除風險」 |
| 用途與分區 | 工業住宅、一般事務所寫成住宅；農地寫成建地 | 照登記資料與使用分區寫 |
| 交通距離 | 「捷運站旁」「5 分鐘到市中心」沒寫怎麼量 | 「距 {地標} 約 {X} 公尺（地圖步行路線估算）」 |
| 規劃中建設 | 把規劃中的捷運、重劃、學校寫成已完成 | 加註「規劃中，以主管機關公告為準」 |
| 學區 | 「明星學區保證」 | 「學區以當年度教育主管機關公告為準」 |
| 價格比較 | 「全區最低」「低於行情三成」沒有依據 | 「近 12 個月同區同類型成交單價中位數約 X 萬／坪（實價登錄，截至 {日期}）」，或乾脆不比較 |
| 屋況 | 「無漏水」「非凶宅」沒查證 | 依不動產說明書與屋況說明書寫；屋主口述要寫「依屋主告知」 |
| 車位 | 總價含車位卻沒說、車位坪數混在室內坪 | 寫明車位含／不含、型式、坪數 |
| 照片 | 他間照片、網路圖庫、AI 生成圖當實景 | 只用本物件實拍；示意圖、虛擬家具標「示意」 |
| 已成交 | 成交後貼文留著當招攬 | 成交／下架當天刪文（見 social-posting-planner） |

### 四張詞表

1. **法遵禁用**（命中必改）：保證增值、穩賺、必漲、包漲、保證獲利、零風險、穩賺不賠、投報率保證、全區最低價、全市最便宜、第一名、唯一、100%、保證貸款八成、保證過件、保證可建、保證可變更、保證可蓋農舍、一定賣得掉、最後一戶（非事實時）、明星學區保證、捷運站旁（量不到時）。
2. **誇飾廉價感**（建議改）：絕版、夢幻、超值、CP 值、稀有、搶手、不容錯過、千載難逢、驚嘆號、「非常」「超級」、同一個表情符號連用 3 個以上。
3. **平台紅線**（命中必改，平台會降觸及或判成垃圾訊息）：標記朋友、tag 一個、按讚分享、按讚如果你同意、覺得有用按愛心；釣魚標題如「你絕對不會相信」「99% 的人都不知道」「震驚」「沒人告訴你的」。
4. **AI 腔**（命中 2 個以上整篇重寫，1 個就改句）：在這個瞬息萬變的時代、讓我們一起、讓我們來看看、想像一下、值得注意的是、綜上所述、總結而言、不僅如此、由此可見、作為一個專業；「不是…而是…」對比句一篇超過 1 組也要改。

### 其他寫法規則

- 只用事實卡寫。屋主或同事寫的原始描述只當參考，不照抄。
- 數字一律帶單位與資料日期。外部數字（行情、統計）資料日期超過 30 天，改成不寫數字或標「待更新」。
- 單位不混用：買賣「萬」、租金「元／月」；1 億以上寫「X.X 億」。
- 標題太長就重寫成短句，不從中間截斷。
- 行動呼籲一篇只放一個（私訊、留言、加 LINE 擇一）；不寫「限時」「名額有限」這類壓迫語。
- 主題標籤：FB 2–4 個；Threads 一篇只放 1 個；LINE 不放。標籤由參數組成，例如 `#{縣市}買房`、`#{行政區}{類型}`。
- 租屋文：寫清楚租金含不含管理費；可否入籍、報稅、申請租金補貼只寫查證過的。
- 土地文：使用分區、面寬、臨路寬度要有依據；「可建」寫成「依 {來源} 為 {分區}，實際能否建築以主管機關審查為準」。
- 年份與節日不要寫死在範本裡（會過期），用「近期」或由當天日期帶入。

### 印刷品格式（報紙分類稿、DM、售屋招牌）

印刷品同樣是廣告：三道門檻、四張詞表、去敏規則全部照用。不動產廣告稿要由經紀業指派的經紀人簽章；印刷品在付印前完成簽章並留存定稿，付印後就改不了。
依據：不動產經紀業管理條例第 21 條（簽委託契約後才可刊登廣告，內容應與事實相符並註明經紀業名稱）、第 22 條第 1 項第 4 款（不動產廣告稿應由經紀業指派經紀人簽章）（全國法規資料庫，查證日 2026-10-03）。

- **報紙分類稿**：標題不超過 `{報紙標題字數上限}`（預設 8 字）、說明不超過 `{報紙說明字數上限}`（預設 12 字），數字、單位、標點都算一個字。超過就重寫成短語（「{行政區}景觀三房」），不從中間截斷。一則只放一個主賣點；總價寫「萬」。經紀業名稱（加盟店含加盟標示）放在整版的固定位置，由租戶設定帶入。
- **DM 物件表**（一頁多件的物件表格或海報）：每件固定欄位＝物件代號、標題（沿用報紙字數上限）、行政區（最多到路段）、類型、總價、坪數（權狀坪與主建物坪，或土地坪）、格局、樓層／總樓層、屋齡、1–3 個賣點、實拍照 1 張。整份 DM 印一次經紀業名稱（含加盟標示）、經紀人員姓名、`{聯絡方式}`。
- **售屋招牌／布條**：遠看要讀得到，所以欄位最少：大字「售」或「租」、一個類型或特色短語（如「三房車位」「{X} 坪建地」）、`{聯絡方式}`、經紀業名稱（含加盟標示）；經紀人員姓名可小字。總價要屋主同意才寫。
  - 掛設要屋主書面同意（寫在委託書或另簽同意書）；沒有同意紀錄不產招牌稿，列「待確認」。
  - 只掛在委託物件本身或屋主同意的位置；不貼電線桿、路樹、公有設施（各縣市廣告物管理規定）。
  - 成交、下架或委託到期當天拆除，列進 social-posting-planner 的下架清單一起追。
- **印刷有時差**：報紙與 DM 從交稿到見報、發送要好幾天，而且印出去收不回來。交稿前與付印前各再確認一次「銷售中」；物件代號記進「已印刷清單」，成交後下一期撤下、剩下的 DM 停發。
- 印刷品一律不放門牌、巷弄號、戶別、屋主資訊；電話只用 `{聯絡方式}` 參數，不寫在範本或事實卡以外的地方。
- 照片只用本物件實拍；張數、尺寸、解析度依稿約，沒有稿約時列「待確認」，不自己猜。

## Checklist（檢查清單）

- [ ] 有效委託與「銷售中」都有依據與確認時間。
- [ ] 經紀業名稱（加盟店含加盟標示）、經紀人員姓名已附；證書字號已附或標「建議補」。
- [ ] 地址只到路／街／段；沒有門牌、戶別、屋主資訊。
- [ ] 每個賣點都對得到事實卡欄位與來源。
- [ ] 坪數已拆分說明、增建另列、規劃中建設已加註。
- [ ] 四張詞表都掃過，命中都已改寫或刪除。
- [ ] 各平台版本的價格、坪數、房數、樓層一致。
- [ ] 只有一個行動呼籲；標籤數量符合平台。
- [ ] 字數在平台範圍內；報紙標題、說明沒有超過字數上限（重寫，不截斷）。
- [ ] 印刷品：交稿前與付印前都確認過銷售中；付印前經紀人已簽章；已記進已印刷清單；招牌有屋主同意紀錄。
- [ ] 最後一行註明「草稿，由仲介本人確認後在自己的帳號貼出」。

## Output requirements（輸出要求）

- 先給各平台草稿，再給「事實對照表」「命中詞與改寫」「待確認」。
- 三道門檻任一不過：不給草稿，只列出缺什麼、要去哪裡補。
- `json` 模式只輸出一個合法 JSON 物件，不加其他文字。
- 印刷品稿件另附「字數表」（標題 {n}/{上限}、說明 {n}/{上限}）與「交稿前、付印前再確認銷售中」提醒；不宣稱已交稿或已付印。
- 不宣稱已發文、已排程、已推播；不產生任何自動發文程式或步驟。

## Test cases（測試案例，全部為合成資料）

**T1 正常三平台：** 示範市河濱區華廈，總價 1,280 萬（含坡道平面車位），權狀 32 坪＝主建物 20＋附屬 2＋公設 7＋車位 3，3 房 2 廳 2 衛，7/12 樓，屋齡 18 年，專任委託未到期，揭露齊全。期望：FB／Threads／LINE 三版；坪數拆分寫出；「含車位」寫明；FB 標籤 ≤ 4、Threads 1 個、LINE 0 個；三版數字一致。

**T2 違規詞：** 原始描述「捷運站旁，保證增值，全區最低價！！稀有釋出」；事實卡寫距「規劃中」捷運站約 1.2 公里、沒有行情資料。期望：刪「保證增值」「全區最低價」，改「稀有」與驚嘆號；「捷運站旁」改成「距規劃中捷運站約 1.2 公里（規劃中，以主管機關公告為準）」；「無行情依據」列入待確認。

**T3 擋下不寫：** 委託到期日已過 5 天；另一筆事實卡沒有經紀業名稱。期望：兩筆都不產草稿，分別回報「委託已到期，請先續約」「缺經紀業名稱，請到租戶設定補上」。

**T4 增建：** 示範市山腳區透天，第 4 層是頂樓加蓋，屋主說「5 房」，其中 1 房在加蓋層。期望：寫「登記 4 房＋增建 1 房（增建部分非登記面積，有被拆除風險）」；權狀坪數不含增建。

**T5 去敏：** 事實卡附完整門牌「{路}{X}巷{Y}號{Z}樓」與屋主姓氏、出售原因「調職」。期望：文案只到路段；屋主姓氏與出售原因不出現；「命中與改寫」註明已去敏。

**T6 JSON 單平台：** `輸出=json`、平台只要 `threads`。期望：合法 JSON；`variants` 只有 1 筆；`hashtags` 長度 1；`compliance` 與 `note` 欄位齊全。

**T7 AI 腔：** 草稿出現「在這個瞬息萬變的時代」「值得注意的是」「綜上所述」。期望：命中 3 個，整篇重寫，重寫後 0 命中。

**T8 報紙稿字數：** 用 T1 的事實卡，平台 `print_newspaper`；初稿標題「河濱區景觀三房華廈附車位」（12 字）。期望：重寫成 8 字以內（例如「河濱景觀三房」），不是截成前 8 字；說明 12 字以內（例如「1280萬含車位7樓」）；不含門牌與電話號碼，聯絡方式用參數；經紀業名稱在整版固定位置。

**T9 招牌與已印刷物件：** 一筆事實卡要做 `sale_sign`，但委託書沒有掛設同意、也沒有另簽同意書；另一筆物件已在上週交稿的 DM 裡，今天成交。期望：招牌不產稿，列「待確認：屋主掛設同意」；成交那筆提醒「下一期 DM 撤下、剩下的停發」，招牌（若有）當天拆。

## Acceptance criteria（驗收標準）

- 每一句文案都能在事實對照表找到欄位與來源。
- 法遵禁用與平台紅線 0 命中；誇飾與 AI 腔命中都有改寫紀錄。
- 每個平台版本都有經紀業名稱（加盟店含加盟標示）與經紀人員姓名；印刷品至少每份（報紙整版、DM 整份、每面招牌）有一次。
- 報紙標題與說明的字數一定在上限內，而且是重寫過的完整短語。
- 沒有門牌、戶別、屋主資訊；人名只有仲介本人（由參數帶入）。
- 不含任何對外動作；輸出可在發文前由仲介逐字修改。
