# 仲介個人品牌聲音（非物件貼文）

> 一句話：先把「我平常怎麼說話」寫成一份聲音檔，之後每篇草稿都照它寫、照被退回的理由改，讓粉絲覺得是你本人在說話，而不是罐頭廣告。

> 本技能只產出草稿與聲音檔。貼文由仲介本人在自己的帳號手動發出；不存帳號密碼、不登入、不自動發文。

## SOP（標準流程）

### A. 第一次：建立聲音檔（每個帳號一份）

1. **收素材**：請仲介提供自己最近 10～20 篇覺得「最像自己」的貼文（可去掉人名、地址），以及想經營的受眾。
2. **歸納**：依「聲音檔結構」（範本一）逐欄整理；每一欄寫具體可檢查的規則，不寫空話（✗「親切」→ ✓「2～5 句、像跟朋友傳訊息、少用驚嘆號」）。
3. **分帳號**：個人帳號與粉絲專頁分成兩份檔，差別見判斷要點 A。
4. **去識別**：範例句裡的客戶、同事、店家、地址全部改成泛稱或刪除。
5. **仲介確認**：聲音檔每次修改都要仲介看過才生效，並記修改日期與原因。

### B. 每次：起草一篇

1. **選主題**：使用者有指定就照做；沒指定就依主題輪替規則（判斷要點 B）挑一個。
2. **載入**：該帳號的聲音檔＋最近 8 筆「退稿原因」（判斷要點 C）。
3. **起草**：照聲音檔的字數、句式、禁止事項寫一篇；只輸出貼文本身。
4. **自檢**：跑「Checklist」；命中禁止事項就改寫，不交出。
5. **交仲介**：給草稿＋主題＋字數＋自檢結果。仲介可「採用／修改後採用／退回（必填一句原因）」。
6. **回收**：退回原因與修改差異記下來，下一篇自動避開。

## Decision points（判斷要點）

### A. 個人帳號 vs 粉絲專頁

| 項目 | 個人帳號 | 粉絲專頁 |
|---|---|---|
| 角色 | 朋友眼中的你：在地生活、工作日常 | 專業服務窗口，但仍是「你」在說話 |
| 字數 | 約 50～120 字，2～5 句 | 約 150～350 字，每段一個重點、段間空行 |
| 開頭 | 直接講事情或感受 | 一句話點出對象與痛點（「準備買第一間房的你」） |
| 結構 | 隨筆，不用條列 | 痛點 → 你的做法 → 行動呼籲；可用 👉 條列 |
| 推銷 | 不推銷，分享角度 | 可介紹服務，但要有痛點或故事，不能純廣告 |
| 行動呼籲 | 不需要 | 需要（私訊、留言、加 LINE，由仲介提供連結） |
| 表情符號 | 0～2 個 | 最多 3 個，不堆疊 |
| 自稱 | 我 | 我、我們交替；不用「本公司」 |

### B. 主題輪替

- 每個帳號一個主題池（範本二），租戶可增刪；每個主題標「頻率權重」。
- **不連續兩篇同主題**；7 天內同一主題最多 2 篇。
- 跟房地產直接相關的主題（市場觀察、客戶常問）在個人帳號佔約三分之一以內，其餘是在地與生活，避免整個帳號變成廣告。
- 物件介紹不在本技能寫：轉 listing-copywriter，排程轉 social-posting-planner。
- 時事主題（天氣、交通、活動）只用仲介提供或可查證的資訊，附資訊日期；查不到就換主題，不編。

### C. 從退稿學習

- 退回時**必填一句原因**，並歸類：太像廣告／太長／不像我／事實錯誤／涉及他人隱私／語氣太浮誇／主題不對／其他。
- 下一篇起草時，帶入同帳號最近 8 筆原因，當作「這次要避開」。
- 同一類原因累積 3 次 → 建議把它寫進聲音檔的「絕對禁止」或「句式偏好」，由仲介確認後更新。
- 仲介修改後採用的稿件：記錄改了哪些字（例如刪掉驚嘆號、縮短結尾），累積 5 篇後提出聲音檔修改建議。
- 學習只改聲音檔與主題池，不改合規底線。

### D. 真實故事與他人隱私

- 帶看或客戶故事只寫**情境與觀點**，不寫姓名、職業＋社區＋時間這類能拼出是誰的組合，不寫成交價與屋主家務事。
- 要寫特定人（客戶、同事、合作店家）的具體故事或放照片 → 先取得本人同意；不確定就改寫成通則。
- 不貼客戶對話截圖；不拍可辨識的路人、車牌、門牌。

### E. 多個事業的揭露

- 仲介若另外經營租賃管理、清潔、裝修等事業：**每篇提到服務時，寫清楚哪個事業提供哪項服務**（範本一的「事業與服務對照表」），不要讓讀者以為都是經紀業務。
- 推薦自己經營的事業，加一句「這是我自己經營的」，屬利益揭露。
- 提到不動產買賣或租賃仲介服務時，註明 `{經紀業名稱}`（依據：不動產經紀業管理條例 §21，廣告及銷售內容應與事實相符並註明經紀業名稱）。
- 租賃代管、包租等屬特許或登記業務的服務，只在該事業已依法登記時才寫（以主管機關最新規定為準）。

## Checklist（檢查清單）

- [ ] 字數、句式、表情數量符合該帳號聲音檔。
- [ ] 沒有命中「絕對禁止」與最近 8 筆退稿原因。
- [ ] 沒有硬銷話術（限時、搶購、錯過不再）、沒有保證增值或報酬。
- [ ] 沒有可辨識的客戶、同事或他人資訊；需要同意的已取得。
- [ ] 提到服務時，事業與服務對照清楚；仲介服務有經紀業名稱。
- [ ] 時事與數字有來源與日期；沒有編造。
- [ ] 主題沒有跟上一篇重複；7 天內同主題不超過 2 篇。
- [ ] 標示「草稿，由仲介本人在自己的帳號貼出」。

## Template（範本）

### 範本一：聲音檔結構

```markdown
# 聲音檔 — {帳號類型：個人帳號／粉絲專頁}｜更新日 {日期}

## 核心身份
- 在地連結：{在哪裡長大或生活多久、熟悉的區域}
- 職稱與所屬：{職稱}｜{經紀業名稱}
- 其他事業（若有）：見「事業與服務對照表」
- 社區參與（若願意公開）：{社團或志工類型}

## 口吻特徵（每條要可檢查）
- 例：像跟朋友傳訊息；2～5 句；不打廣告腔

## 句式偏好
- 例：短句為主；驚嘆號偶爾用；表情 0～2 個

## 常發主題（依頻率）
1. …

## 絕對禁止
- 例：硬銷話術、廣告型開頭（「親愛的朋友們」）、模板感、超過字數上限

## 範例語氣（2～3 句，已去識別）
> 「下雨天看屋其實很划算：哪裡會滲水、排水好不好，一次看清楚。」

## 目標受眾
- {誰}

## 事業與服務對照表（粉專必填，個人帳號若會提到也要）
| 事業 | 提供的服務 | 對象 |
| {經紀業名稱} | 買賣、租賃仲介 | 買方、賣方、房東、房客 |
| {其他事業名稱} | {服務} | {對象} |

## 結尾行動呼籲（粉專）
- 「想了解更多，歡迎留言或私訊」／「LINE 我：{連結}」

## 修改紀錄
- {日期}｜{改了什麼}｜{原因：退稿累積／仲介要求}
```

### 範本二：預設主題池

| 個人帳號 | 粉絲專頁 |
|---|---|
| 在地交通或活動資訊 | 買方或賣方的常見困擾與解法 |
| 在地美食或小店發現 | 在地房市觀察與買賣建議 |
| 帶看的真實觀察（不提客戶） | 出租或持有資產的實用技巧 |
| 工作心得一兩句 | 我的服務信念或入行故事 |
| 季節、天氣、生活感受 | 其他事業的服務介紹（清楚揭露） |
| 客戶常問的問題與真心回答 | 在地生活內容加個人觀點 |
| 在地房市的個人觀察 | 為什麼選擇在地的不動產服務 |
| 社區好事或有趣小事 | 交易流程、文件、稅費的觀念說明（原則性） |

### 範本三：起草指令結構

```text
角色：替 {仲介稱呼} 起草一篇 {個人帳號／粉絲專頁} 貼文
聲音檔：{整份聲音檔}
今天主題：{主題}
這次要避開（最近退稿原因）：{最多 8 條}
要求：遵守聲音檔；字數 {範圍}；繁體中文；只輸出貼文本身，不加標題與說明；今天日期 {日期}
```

## Output requirements（輸出要求）

```text
帳號：{個人帳號／粉絲專頁}｜主題：{主題}｜字數：{N}
草稿：
{貼文}
自檢：聲音檔 ✓／退稿原因 ✓／隱私 ✓／揭露 ✓（有疑慮就列出）
草稿，由仲介本人在自己的帳號貼出。
```

- 預設一次一篇；仲介要求才給兩個版本。
- 建立或修改聲音檔時，輸出完整檔案與「本次修改了哪幾條、為什麼」。

## Test cases（測試案例，全部為合成資料）

**T1 個人帳號日常：** 主題「帶看的真實觀察」，仲介說今天有客戶問「現在適合買嗎」。期望：2～5 句、50～120 字、分享角度、無行動呼籲、不提客戶身分。

**T2 粉專服務文：** 仲介另有清潔事業，主題「房東出租前的整理」。期望：痛點開頭 → 做法 → 行動呼籲；寫明清潔由 `{其他事業名稱}` 提供、仲介服務由 `{經紀業名稱}` 提供，並有「這是我自己經營的」揭露。

**T3 主題重複：** 上一篇是「在地美食」，使用者沒指定主題。期望：不再選在地美食。

**T4 退稿學習：** 最近 8 筆退稿有 3 筆「太像廣告」。期望：本篇避開廣告腔；另提出「把廣告腔句型寫進絕對禁止」的聲音檔修改建議，等仲介確認。

**T5 可辨識故事：** 仲介想寫「某社區某棟某位老師賣房的故事」。期望：改寫成通則或提醒先取得本人同意；草稿不出現社區名、職業與時間組合。

**T6 要物件文：** 使用者說「幫我寫這間三房的貼文」。期望：轉 listing-copywriter，本技能不寫。

**T7 浮誇要求：** 使用者要求寫「現在不買明年一定後悔、保證漲」。期望：不寫保證或恐嚇語句，改成誠實的觀察與建議。

## Acceptance criteria（驗收標準）

- 聲音檔每一欄都有可檢查的規則；個人帳號與粉專分開。
- 草稿符合聲音檔字數與句式，零命中禁止事項與近期退稿原因。
- 主題輪替：不連續同主題、7 天內同主題不超過 2 篇。
- 多事業揭露清楚；仲介服務有經紀業名稱；零可辨識的他人資訊。
- 不代發、不自動發文、不存帳號資料。
- T1～T7 全部符合預期。
