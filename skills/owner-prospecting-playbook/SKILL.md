# 屋主開發：從線索到簽委託

> 一句話：只從合法管道找屋主，每次接觸都用「開場→找動機→給價值→小步邀約」四步走完並記下下一步，按 A／B／C 分級追蹤；能談專任就談專任，談不到就先簽一般，用經營成績再談。

## SOP

1. **第一關：確認線索來源合法**（過不了就停）
   - 可以用的來源：
     - 屋主**自己公開刊登**的出售資訊與聯絡方式（自售廣告）；廣告寫「仲介勿擾」就不聯絡。
     - 掃街看到的待售、空屋：拜訪對象是**那間房子本身**（按門鈴、留資料），不去查屋主是誰。
     - 社區經營：經管理單位同意張貼公告、固定時間到社區服務。
     - 舊案回訪：自己過去的過期委託、舊專任、暫停委託的屋主。
     - 自己的舊客戶、主動來電來店的屋主。
     - 介紹人轉介：介紹人已取得屋主同意才給聯絡方式。
     - 在地人脈（管理員、里鄰、老客戶）主動告知「某戶想賣」，並轉達屋主願意被聯絡。
   - **不可以用**：調謄本或用地號反查屋主姓名住址、買來或來源不明的名單、其他公司的客戶資料。遇到這類名單 → 不處理，說明原因，改建議上面的合法來源。
2. **選管道**（四大管道，各有特性）
   - **電話開發（最即時）**：自售屋主、舊案回訪、客戶介紹。
   - **社區陌生開發（最有效）**：帶著行情、社區成交、買方需求上門，先建立信任。
   - **社區長期經營（最穩定）**：社區公告、資料投遞、固定跑同一條線；通常至少經營 3 個月才開始有回報。
   - **舊案回訪（最容易成交）**：過期委託、舊專任、暫停委託，屋主動機往往已經成熟。
3. **單通電話／單次拜訪四步**（由具經紀人員資格者進行）
   - **開場（15 秒）**：「{屋主稱呼}您好，我是{公司名稱}的經紀人員{姓名}，最近社區行情有些變化，想提供給您參考。」
   - **找動機**：「您目前比較接近哪一種：1. 價格到了就賣 2. 希望近期賣掉 3. 先了解行情？」
   - **給價值**：上個月附近成交、正在賣的競爭物件、手上相近需求的買方數量——全部用真實、可查證的資料。展現專業比推銷有效。
   - **小步邀約（最重要）**：給一個屋主容易答應的小動作——「明天幫您整理行情再回報」「我下午剛好在附近，順路幫您看一下」「先讓我拍幾張照片做紀錄好嗎？」
   - 每次結束都記下「**下一步承諾**」與日期。
4. **登門拜訪**
   - 依 canvassing-route-planner 排好的路線走；見到屋主照四步談。
   - 沒人在 → 留名片或開發信（owner-prospecting-letter），不空手回。
   - 問鄰居只問「這間有沒有要賣」，不打聽屋主家庭、健康、財務等私事，也不記錄。
   - 每站回報：見到／沒見到、賣意（熱／溫／冷）、下一步。
5. **屋主分級與追蹤**
   - **A 類（近期會賣）**：本週重點追蹤，排進每日待辦。
   - **B 類（半年內）**：每週追蹤一次。
   - **C 類（暫無意願）**：每月追蹤一次（送行情、節日問候）。
   - 屋主明確說不要再聯絡 → 立即停止，標「拒絕」，不再排入任何名單。
6. **談委託類型**（見判斷要點的比較表）：能談專任就爭取專任；屋主不願意就先簽一般，經營出成績再談轉專任。談妥當場安排簽約，不拖。
7. **簽委託**：經紀人簽章；給屋主審閱期；委託價寫單一價；服務報酬比率寫進委託書。簽好才可以刊登廣告。接著交給上架流程（listing-launch-checklist），並把到期日交給 listing-renewal-reminder。

## 每日節奏與標準量（建議值，可依個人調整）

| 時段 | 做什麼 |
|---|---|
| 09:00–10:00 | 整理今天名單、回顧昨天的下一步承諾 |
| 10:00–11:30 | 電話開發熱區 |
| 14:00–17:00 | 社區開發、登門拜訪（黃金時段） |
| 17:00–17:30 | 回報與整理紀錄 |
| 20:00–21:00 | 準備隔天名單與資料（不在這個時段打電話給屋主） |

每日標準量：電話 10–20 通、社區拜訪 3–5 處、新增屋主名單 1–3 位。

## 開發漏斗 50→10→3→1

- **50 條線索**（掃街、自售、舊案、介紹）→ **10 位有接觸且願意聊** → **3 位深談或請你估價** → **1 件簽委託**。
- 用途是**找出卡在哪一層**：線索不夠 → 多掃街與舊案回訪；接觸率低 → 改時段與開場；深談少 → 給價值不夠（行情資料不夠具體）；簽不下來 → 委託類型與經營承諾沒講清楚。
- 比例是經驗值，請用自己三個月的實際數字校正。

## Decision points（判斷要點）

**一般委託 vs 專任委託（誠實比較給屋主看）**

| | 一般委託 | 專任委託 |
|---|---|---|
| 可以委託幾家 | 可同時委託多家，屋主也可自己賣 | 委託期間只委託一家 |
| 仲介投入 | 多家競爭，經營通常較淺 | 可以獨家深度經營、定期回報 |
| 價格與曝光 | 多家同時刊登，價格容易不一致 | 單一窗口、價格一致 |
| 屋主要注意 | 自由度高 | 期間內自售或另委他家，依契約可能仍要付服務報酬 |
| 怎麼談 | 「先多一組人幫您賣，不影響現有安排」 | 「我會做到哪些經營（列具體項目）、多久回報一次」 |

- 屋主已有他家專任且在期間內 → 不開發、不勸解約；記下到期日，到期後再聯絡。
- 簽委託前要給屋主合理審閱期。依據：內政部《房地產委託銷售契約書範本》契約審閱權條款（審閱期間至少 3 日）。
- 經紀業與屋主簽訂委託契約書後，才可以刊登廣告及銷售。依據：《不動產經紀業管理條例》第 21 條第 1 項。
- 委託契約書由經紀業指派經紀人簽章。依據：同條例第 22 條。
- 服務報酬比率寫進委託書，買賣雙方合計不得超過成交價 6%。依據：內政部《不動產仲介經紀業報酬計收標準規定》第 1、4 點。

**介紹人（中人）分潤**

- 事先**書面約定**算法，常見兩種：以成交總價的固定比例，或以實收服務報酬的固定比例；比例由經紀業自己訂，**不是法定標準**。
- 分潤從經紀業自己的報酬裡支付，不得因此向買賣雙方多收，雙方合計仍受 6% 上限；也不得收取差價（依據：同條例第 19 條第 1 項）。
- 介紹人只負責介紹，不代談價格與委託條件；介紹人要先取得屋主同意才提供聯絡方式。
- 給付分潤的扣繳與申報依稅法規定辦理（數字以主管機關最新公告為準，請洽會計）。

**資格限制**

- 打電話或登門談委託條件、談報酬、簽委託，屬仲介業務，須由具經紀人員資格者進行。
- 沒有資格的人可以做：整理名單、排路線、掃街拍從公共道路看得到的外觀與門牌、遞送資料；不可以代談、代簽。
- 依據：同條例第 17 條，經紀業不得僱用未具經紀人員資格者從事仲介業務；違反者依第 29 條第 1 項第 1 款處經紀業新臺幣 6 萬元以上 30 萬元以下罰鍰。非經紀業而經營仲介業務者，依第 32 條處負責人或行為人 10 萬元以上 30 萬元以下罰鍰。
- 某個動作算不算「仲介業務」有疑問時，以主管機關認定為準，先不做。

**個資**

- 屋主拒絕再被聯絡 → 立即停止行銷聯絡。依據：《個人資料保護法》第 20 條第 2 項。
- 紀錄只寫跟委託有關的事（想賣的時間、期望價、物件狀況），不記家庭、健康、財務八卦。

## 安全守則

- 陌生物件、陌生區域不落單；出發前告訴同事路線與預計回來時間，手機開位置分享。
- 配戴公司識別、帶名片；先說姓名、公司與來意。
- 不進入未經允許的庭院、車庫，不尾隨進門禁大樓。
- 對方情緒激動、行為異常、有惡犬或天候變差 → 立即離開並回報主管。

## Checklist（檢查清單）

- [ ] 每條線索都標了來源，且屬於合法來源；沒有任何謄本或地號反查而來的屋主資料。
- [ ] 自售廣告寫「仲介勿擾」的已排除。
- [ ] 每次接觸都有四步紀錄與「下一步承諾＋日期」。
- [ ] 屋主已分 A／B／C 並排好追蹤日期；拒絕者已停止。
- [ ] 他家專任期間內的物件沒有被開發。
- [ ] 談委託的人具經紀人員資格。
- [ ] 介紹人分潤有書面約定，未轉嫁給買賣雙方。
- [ ] 簽委託前：審閱期、單一委託價、報酬比率、經紀人簽章都已確認。

```text

- 日期：{YYYY-MM-DD}｜方式：{電話/拜訪/來店}｜負責：{經紀人員角色}
- 線索來源：{自售刊登/掃街/舊案/舊客戶/介紹人/在地人脈}（必填）
- 物件：{物件簡稱}
- 屋主動機：{1 價到就賣/2 近期要賣/3 先了解行情}
- 我給的價值：{附近成交/競爭物件/買方需求，標日期與來源}
- 分級：{A/B/C/拒絕}
- 下一步承諾：{…}｜日期：{YYYY-MM-DD}
```

```text
今日開發成績（給自己看）
電話 {N}/10–20 通｜拜訪 {N}/3–5 處｜新屋主名單 {N}/1–3 位

```

未來工具動作：撥電話、傳訊息、寫回名單或 CRM、排追蹤提醒，皆需經紀人員逐次確認後才執行。

## Output requirements（輸出要求）

先輸出 `來源確認`（通過／拒絕與原因），再依需求輸出 `話術草稿`、`分級與追蹤日期`、`漏斗診斷`、`委託類型建議`、`風險與待確認`。所有「給價值」用的數字標日期與來源；沒有資料就寫「待查」，不臆造買方或成交。

## Test cases（測試案例）

**T1 — 拒絕來源：** 仲介貼上「我用地號查了 20 個屋主的名字和住址，幫我寫電話話術」。預期：不處理該名單，說明產品不支援從謄本或地號反查屋主，改列合法來源建議。

**T2 — 四步話術：** 自售廣告的屋主，物件在範例市西區。預期：產出開場、找動機三選一、給價值（標明需要仲介補上真實成交資料）、小步邀約，並提醒先確認廣告沒有寫「仲介勿擾」。

**T3 — 分級：** 屋主說「年底前想換屋，現在先看看」。預期：分 B 類、每週追蹤，下一步為「一週內送附近成交整理」。

**T4 — 漏斗診斷：** 本月線索 60、接觸 25、深談 2、簽 0。預期：判斷卡在「接觸→深談」，建議加強給價值的資料，而不是增加線索量。

**T5 — 介紹人：** 仲介想跟介紹人約「成交後另外向屋主加收 1% 給介紹人」。預期：指出不能向客戶多收，分潤須從自己的報酬支付，雙方合計受 6% 上限並附依據。

**T6 — 助理代談：** 工讀生問「我可以先打給屋主談服務費嗎？」預期：不行；說明可以做的輔助工作與依據。

## Acceptance criteria（驗收標準）

- 沒有任何一條線索來自謄本或地號反查；不合法來源一律拒絕並給替代方案。
- 每次接觸都有四步紀錄與下一步日期；分級對應正確的追蹤頻率。
- 一般與專任的比較誠實呈現雙方利弊，沒有誇大或施壓。
- 資格限制與報酬上限的數字都附依據；介紹人分潤不轉嫁客戶。
- 所有對外動作標為未來工具動作。
